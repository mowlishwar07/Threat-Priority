Column mapping and supported schema

Canonical fields: duration (seconds), src_bytes, dst_bytes, src_packets, dst_packets, failed_logins, unique_dst_ports, protocol, service. At least 3 usable fields per row. Optional: timestamp (ISO or Unix seconds), label (0 benign / 1 attack).

Aliases: dur, sbytes, dbytes, spkts, dpkts, proto, ts, class. Convert units before uploading. A different dataset needs retraining.

Replay sends one bundled synthetic event every second through the ingestion API. It is not a live network capture. No external services are used.
